# UTS-Kelompok-2

Alasan Kami memilih projek berupa Sistem Administrasi Penerimaan Mahasiswa Baru dikarenakan adanya beberapa kendala terkait administrasi penerimaan mahasiswa baru dengan contoh ada beberapa mahasiswa baru yang tidak terdata, tidak sengajanya data terhapus dsb. Sehingga menghambat pendataan mahasiswa baru dan ditakutkan terjadi lebih banyak masalah yang lebih fatal.
